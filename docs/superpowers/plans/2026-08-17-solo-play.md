# 1人プレイ対応 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 最小人数を2から1に下げ、1人でも「相手が見えない対話」形式の一人芝居を演じて採点まで到達できるようにする。

**Architecture:** 進行ロジック（準備同期・録音・アップロード収集・採点・ロビー復帰）は在室者の集合を数えるだけで人数を仮定していないため無改造。変更は①ガードの緩和 ②台本検証の緩和 ③ソロ用コンテンツ（手書き台本1本＋AIプロンプト分岐）④クライアントのボタン条件、の4方向に閉じる。ソロ台本は `minPlayers: 1, maxPlayers: 1` とすることで `selectPlay` の既存の人数フィルタだけで既存の対話劇と棲み分かれる（選択ロジックは無改造）。

**Tech Stack:** TypeScript / Node.js `node:test` (tsx) / Socket.IO / React + Vite

**Spec:** `docs/superpowers/specs/2026-08-17-solo-play-design.md`

## Global Constraints

- サーバーは `tsx` 実行で**型チェックされない**。`npx tsc --noEmit` が実質のゲート。各タスクの最後に走らせる。
- テストは `server/` で `npm test`、クライアントは `client/` で `npm test` と `npm run build`。
- 共有の型・定数はリポジトリ直下 `shared/` に置き、`@shared/*` エイリアスで両側から import する。
- コミットメッセージは日本語。末尾に `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` を付ける。
- ソロ台本の尺基準: **10〜12行、`line` の合計360字以内**。実測条件は4字/秒＋行間0.8秒/行、これに「聞く間」を1箇所3秒で加算し、**合計150秒未満**に収める。
- 「相手が見えない対話」の執筆規約: ①相手の台詞は書かない ②`action` に演者が黙る間を明示する ③最終行に山を置く。
- TDD 厳守。失敗するテストを書き、**実際に失敗を確認してから**実装する。
